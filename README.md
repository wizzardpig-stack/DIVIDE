# DIVIDE

An interactive population visualizer about how layers of identity, affiliation, geography, and social sorting can progressively divide a shared population. The experience is designed around a live field rather than static charts.

## Live

https://wizzardpig-stack.github.io/DIVIDE/

## What it demonstrates

- Canvas-based population visualization with layered filtering
- Interactive history and division-state controls
- Dedicated mobile composition with a bottom tray and slide-up control sheet
- Horizontal touch-friendly history navigation
- Reduced interface density on small screens without removing the core interaction

## Stack

HTML, CSS, vanilla JavaScript and Canvas.

## Development approach

Independent systems concept, interaction design, visual direction, iterative testing, and AI-assisted implementation. The mobile build is a distinct layout rather than a scaled-down desktop screen.
